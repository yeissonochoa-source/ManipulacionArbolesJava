# Tree-Stock: Sistema de Inventario con Árboles Binarios

## Objetivo
Aplicar el concepto de Árbol Binario de Búsqueda  y su estructura lógica de punteros dinámicos para gestionar un sistema de clasificación o inventario en Java, utilizando control de versiones y trabajo colaborativo.

## Instrucciones de Ejecución
1. Asegúrese de tener instalado el JDK de Eclipse Temurin.
2. Clone este repositorio: `git clone [https://github.com/yeissonochoa-source/ManipulacionArbolesJava]`
3. Abra el proyecto en VS Code.
4. Ejecute el archivo `Main.java`.
5. Utilice el teclado numérico para navegar por las opciones (1, 2, 3, 0) y siga las instrucciones en pantalla.
